The Irresistible Comfort of JetBrains Git (and the Price We Pay)

If you have ever written code in WebStorm, IntelliJ IDEA, or PyCharm, you know that JetBrains built the undisputed gold standard of Git workflows.

It isn’t just about staging files—it’s the muscle memory:

  • Changelists: Effortlessly grouping modified files by logical tasks, keeping experiments separated from hotfixes, and committing selected sets without wrestling with git add -p.
  • Git Shelf: Shelving temporary work with descriptive notes, keeping your working tree pristine without littering git stash with anonymous commits.
  • Interactive Diff Editor: Inspecting changes side-by-side, editing the modified file directly in the diff pane, saving with Cmd+S, and rolling back individual hunks with a single click on a gutter arrow (↩).
  • Keyboard Ergonimics: Pressing F7 / Shift+F7 to jump between changes, and Cmd+Enter to commit.
